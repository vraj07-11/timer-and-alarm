# ⏰ Timer and Alarm Clock

A functional time-management web application featuring a precise timer and alarm clock functionality. Built with vanilla web technologies and includes working audio alerts.

## ✨ Features

- **Countdown Timer:** Set custom hours, minutes, and seconds with start, pause, and reset controls.
- **Timer:** Track elapsed time accurately with split/lap capabilities.
- **Alarm Clock:** Set alarms to notify you when specific times are reached.
- **Audio Alerts:** Built-in working sound notifications that trigger when your timer or alarm goes off.
- **Dynamic UI:** Real-time clock display updating smoothly every second.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Web Audio API / Audio elements)
- **Version Control:** Git & GitHub
